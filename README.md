# Календарь отпусков

Одностраничное web-приложение для отметки отпускных дней в календаре.

## Возможности
- Просмотр месяцев вперед/назад.
- Выбор отпускных дат кликом по дню.
- Повторный клик снимает отметку.
- Список выбранных дат под календарем.
- Сохранение данных в `localStorage`.

## Запуск
Просто откройте файл `index.html` в браузере.
