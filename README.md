# Календарь отпусков

Одностраничное web‑приложение для планирования отпусков сотрудника в корпоративном стиле, близком к mrgeng.ru.

## Что умеет
- Просит ввести ФИО сотрудника при первом открытии.
- Добавляет периоды отпуска с типом: **основной** или **дополнительный**.
- Проверяет ограничения:
  - основной отпуск: максимум 28 дней;
  - дополнительный отпуск: максимум 6 дней;
  - периоды основного отпуска (кроме периода 14+ дней) кратны 7;
  - каждый период дополнительного отпуска кратен 3.
- Позволяет назначить метку **ЕСВ** ровно на один выбранный период.
- Показывает метки на календаре (тип отпуска и ЕСВ).
- Экспортирует данные в `.xlsx` с полями:
  - ФИО,
  - периоды отпусков,
  - период с меткой ЕСВ.

## Запуск
1. Откройте `index.html` в браузере, **или**
2. Запустите локальный сервер:
   ```bash
   python3 -m http.server 8080
   ```
   и откройте `http://localhost:8080`.
